How I approach software development

As a Computer Science student, my portfolio reflects real iterative learning rather than overnight templates. Several projects started as early academic and internship tasks (like my basic Scapy packet sniffer, social platform, and e-commerce storefront) that I later audited systematically for security flaws, brittle DOM rendering, and missing UX states.

Instead of abandoning imperfect code, I upgraded those repositories cleanly — replacing unsafe token validation with salted scrypt + timing-safe HS256 JWT checks, moving innerHTML injections to safe DOM builders, and adding deterministic client fallback adapters so reviewers can test live flows without spinning up local databases first.
